# Tang Mega 138K (GW5AST-138) SNN Accelerator

Портирование спайкового нейросетевого ускорителя распознавания рукописных цифр MNIST на отладочную плату Sipeed Tang Mega 138K (SOM-модуль на несущей плате Tang Console, кристалл Gowin GW5AST-LV138PG484AC1/I0).

## Аппаратная архитектура

- Кристалл: Gowin Arora V GW5AST-LV138PG484AC1/I0
- Системная тактовая частота: 50.0 МГц (активный генератор на выводе V22)
- Нейросетевое ядро: 784 входных рецептора -> 12 нейронов LIF первого слоя -> 10 выходных нейронов классов
- Память весов: 4 блока блочной памяти BSRAM (18-битные слова, упаковка 3 весов по 6 бит)
- Интерфейс обмена: высокоскоростной последовательный порт UART (2 000 000 бод, 8N1) через микроконтроллер-мост Bouffalo Lab BL616
- Физический разъем: порт Type-C `DEBUG|OTG`

## Таблица назначений выводов (CST)

| Сигнал | Вывод FPGA | Стандарт ввода-вывода | Назначение |
| :--- | :--- | :--- | :--- |
| `sys_clk` | `V22` | LVCMOS33 | Системный тактовый генератор 50 МГц |
| `sys_rst_n` | `F4` | LVCMOS15, PULL_UP | Аппаратный сброс (активный низкий) |
| `key_b` | `AB13` | LVCMOS33, PULL_UP | Пользовательская кнопка K2 |
| `uart_rx` | `V14` | LVCMOS33, PULL_UP | Прием данных от моста BL616 |
| `uart_tx` | `U15` | LVCMOS33, DRIVE=8 | Передача данных в мост BL616 |
| `led[0]` | `V13` | LVCMOS33, DRIVE=4 | Светодиод индикации D1 |
| `led[1]` | `P19` | LVCMOS33, DRIVE=8 | Светодиод индикации D2 |
| `led[2]` | `R19` | LVCMOS33, DRIVE=8 | Светодиод индикации D3 |

## Подготовка окружения

### 1. Инструментальная цепочка САПР

Для синтеза и прошивки требуется пакет open-source САПР OSS CAD Suite:
- `yosys` (синтез для архитектуры Gowin GW5A)
- `nextpnr-himbaechel` (размещение и трассировка под кристалл GW5AST-LV138PG484AC1/I0)
- `gowin_pack` (генерация битовой матрицы `top_138k.fs`)
- `openFPGALoader` (программатор по интерфейсу JTAG)

Если пакет распакован в `/home/bobbert/oss-cad-suite`, скрипты сборки и прошивки автоматически добавят его в переменную `PATH`.

### 2. Зависимости Python

Для запуска тестовых скриптов и бенчмарка требуются библиотеки Python 3:

```bash
pip install pyserial numpy pillow scikit-learn
```

### 3. Права доступа к USB-устройствам

Добавьте пользователя в группу `dialout` для доступа к последовательным портам:

```bash
sudo usermod -a -G dialout $USER
```

## Подключение платы

1. Подключите плату к компьютеру кабелем USB Type-C через разъем с маркировкой **`DEBUG|OTG`**.
2. В операционной системе Linux появятся два устройства:
   - `/dev/ttyUSB0` — канал JTAG-отладчика;
   - `/dev/ttyUSB1` — высокоскоростной последовательный порт UART.
3. Убедитесь в обнаружении платы программатором:

```bash
openFPGALoader --detect
```

## Сборка прошивки

Для запуска полной процедуры синтеза, размещения, трассировки и упаковки битовой матрицы выполните:

```bash
./build.sh
```

Скрипт выполнит:
1. Синтез Verilog-описания (`top_138k.v`, `uart_rx.v`, `uart_tx.v`) в `build/top_138k.json` с помощью `yosys`.
2. Трассировку схемы под корпус PG484 с учетом ограничений `tang_mega_138k.cst` в `build/top_138k_pnr.json` с помощью `nextpnr-himbaechel`.
3. Упаковку битовой матрицы в `build/top_138k.fs` с помощью `gowin_pack`.

## Прошивка платы

### Быстрая загрузка в SRAM (до отключения питания)

```bash
./flash.sh
```

### Энергонезависимая запись в SPI Flash память

```bash
./flash.sh -f
```

## Запуск инференса и бенчмарков

### Экспресс-тест (10 контрольных образцов)

Отправка одиночных оцифрованных изображений цифр 0..9 на скорости 2 000 000 бод и вывод предсказанного класса с замером задержки:

```bash
python3 test_client.py --port /dev/ttyUSB1 --baud 2000000
```

### Полный аппаратный бенчмарк (1 000 тестовых изображений MNIST)

Автоматическая загрузка официальной тестовой выборки MNIST, предобработка по алгоритму ЛеКуна (центрирование по центру масс в окне 20x20 и нормализация в 28x28) и поточное аппаратное тестирование по 100 образцов на каждую цифру:

```bash
python3 benchmark_hardware.py
```

Результаты работы скрипта выводят таблицу точности по каждому классу, среднее количество тактов ядра TTFS, чистое время работы цифрового автомата на кристалле и сквозную задержку по интерфейсу USB.
